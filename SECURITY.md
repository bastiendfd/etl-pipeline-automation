# Security Policy

## Supported versions

The latest version on the `main` branch is supported.

## Reporting a vulnerability

Please **do not** open a public issue for a suspected vulnerability. Instead, use GitHub's private vulnerability reporting feature for this repository, or contact the maintainer privately through the email address on the GitHub profile. Include a clear description, reproduction steps, and potential impact.

Reports are acknowledged within seven days when possible. Please do not include credentials, personal data, or production datasets in a report.

## Data handling

This project is designed for synthetic or non-sensitive CSV data. Keep real customer data and secrets out of the repository, command history, fixtures, and issue trackers.
